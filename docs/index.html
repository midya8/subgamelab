Three different questions.

01 / ROOT ONE-NODE STABILITY

Can changing one decision improve the payoff at the root? Coordinated changes by the same player can escape this test.

02 / ROOT NASH

Can one player improve by changing their entire contingent plan? An unreached threat can survive this stronger test.

03 / SUBGAME PERFECTION

Does every continuation pass full-player Nash, including branches with zero reach probability?

Evidence, not a prediction.

This is a bounded implementation of established extensive-form game theory. It is not a new equilibrium concept, formal proof, scalable solver, behavioral model, or evidence of real-agent strength. Only pure contingent strategies are enumerated; mixed equilibria are outside scope. Root one-node stability is named explicitly, not silently substituted for full-player Nash or for the continuation-based one-deviation principle.

Python generation uses dynamic evaluation and backward-induction plan products. Its independent checker enumerates terminal paths and every unilateral subgame alternative. The browser uses BigInt rationals; its replay is same-engine, not an independent verifier. A valid certificate checks included arithmetic, not payoff provenance or real-world rationality.
