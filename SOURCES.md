# Established theory and consulted sources

Consulted 2026-11-10. Links were fetched and relevant text inspected. Definitions and proof are classical, not original contributions.

1. Martin Osborne, *Introduction to Game Theory*, chapter 5, [textbook chapter](https://www.economics.utoronto.ca/osborne/igt/igtChapter5.pdf). Definitions 164.1 and 166.1, off-path requirements, and complete tied backward-induction combinations. Main semantic source. This chapter's basic model does not include chance.
2. Omer Tamuz, Caltech, *Undergraduate Game Theory Lecture Notes*, 2018, [university notes](https://tamuz.caltech.edu/teaching/ps172/lectures.pdf). Finite perfect-information one-deviation principle, subgames, and induction. The principle is about continuation utility, not only root gains.
3. MIT 14.126, spring 2024, [Equilibrium Refinements lecture](https://ocw.mit.edu/courses/14.126-game-theory-spring-2024/mit14_126_s24_lecture_2_refinements.pdf). Singleton information sets, pure SPE existence, and limits of subgame perfection outside perfect information. We do not implement its more general refinements.
4. University of Maryland CMSC 474, 2013, [game-tree lecture](https://www.cs.umd.edu/~hajiagha/474GT15/Lecture12122013.pdf). Finite game-tree search and stochastic outcomes. Chance utility here is the ordinary exact expectation over terminal paths.
5. Vincent Knight, [Subgame Perfection educational chapter](https://vknight.org/gtb/chapters/subgame-perfection/). Existing entry-deterrence teaching pattern and game-theory software context. We developed different numeric controls. Its informal dominated-action wording is not used in place of Osborne's complete contingent-plan correspondence.
6. Gambit, [equilibrium algorithms](https://gambitproject.readthedocs.io/en/stable/algorithms.html), [pure Nash API](https://gambitproject.readthedocs.io/en/stable/api/pygambit.nash.enumpure%5Fsolve.html), and [pure agent-Nash API](https://gambitproject.readthedocs.io/en/stable/api/pygambit.nash.enumpure_agent_solve.html). Existing extensive-form software is acknowledged. Since version 16.5 these are distinct API routes; agent Nash must not be confused with full-player Nash. Gambit installation did not finish in the bounded local attempt. No Gambit validation is claimed.
7. Nashpy, [best-response checks](https://nashpy.readthedocs.io/en/stable/how-to/check-best-responses.html). Actual version 0.0.43 is used as an optional reference on independently input-built subtree normal forms. Its installed implementation uses NumPy isclose. Integer scaling keeps every nonzero tested payoff difference at least one and the largest absolute matrix entry at 18 in the retained corpus. This is a numerical reference, not the exact checker or production dependency.

Subgame perfection is credited to the classical Selten literature as discussed by these sources. We do not claim to have inspected Selten's original paper or to invent the concept. No external implementation code, figures, datasets, parameters or weights were copied. No first implementation, new algorithm, formal verification, scalable multiagent solver or empirical real-world strength claim. The contribution is this bounded implementation, complete evidence format, independent replay, developed controls and interactive inspection.
